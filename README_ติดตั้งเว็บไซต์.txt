การติดตั้ง
1) แตก ZIP แล้วอัปโหลดไฟล์และโฟลเดอร์ทั้งหมดไปที่ root ของ aabgroups.com
2) ตรวจว่าเปิด https://www.aabgroups.com/ , /th/ และ /en/ ได้
3) ลองคลิกสลับ TH/EN บน PC / มือถือ และลองกดรูปแผนที่
4) ตรวจ QR LINE ให้สแกนได้และกดลิงก์ LINE @allaboutbimmer
5) ตรวจสอบเบอร์โทร 092-564-9623 และ 065-562-9898

ข้อควรรู้
- ไม่มีระบบหลังบ้านรับนัดหมาย: ฟอร์มสร้างข้อความให้ลูกค้าคัดลอกไปส่งทาง LINE เท่านั้น
- ภาพ Lounge เป็นภาพ CONCEPT ไม่ใช่การยืนยันสภาพห้องจริง
- รูปแบบ LOGO รักษาอัตราส่วนจริง ห้ามกำหนด width และ height แบบยืดภาพ
- แผนที่เป็นภาพนิ่งที่กดเปิดลิงก์ Google Maps ที่ AAB ให้มา ไม่ใช่แผนที่ API ฝัง
- ปุ่มภาษาใช้หน้า /th/ และ /en/ แยกกัน ไม่ใช้ Google Translate
- เพื่อป้องกันที่อยู่ผิดจากข้อมูลภายนอก ข้อความบนเว็บระบุเพียง 'AAB HQ · ลาดกระบัง กรุงเทพมหานคร' โดยใช้ลิงก์นำทางต้นฉบับ
- ฟอนต์โหลดจาก Google Fonts หากใช้งานออฟไลน์จะมี fallback ตามระบบ
- ควรตรวจสอบว่าระบบเว็บที่ใช้อยู่ (WordPress ฯลฯ) รองรับการวางไฟล์ static ที่ root ได้หรือไม่ก่อนอัปโหลดทับ
- ควรตั้ง redirect หรือ canonical จาก / ไป /th/ หากต้องการลดหน้าซ้ำสำหรับ SEO
