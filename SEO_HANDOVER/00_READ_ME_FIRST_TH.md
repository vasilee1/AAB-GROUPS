## การติดตั้งโดยผู้ดูแลเว็บ
1. สำรองเว็บไซต์เดิมทั้งหมด โดยเฉพาะถ้าปัจจุบันใช้ WordPress/CMS
2. ตรวจว่าโฮสต์สามารถให้บริการ static HTML ที่ root, /th/, /en/ และ subdirectories ได้ โดยไม่ชนกับ routing ของ CMS
3. อัปโหลด CONTENTS ของ ZIP ไปที่ root โดยเก็บโครงสร้างเหมือนเดิม (อย่าอัปโหลดโฟลเดอร์หุ้มอีกชั้น)
4. ตรวจ 12 URL ใน sitemap.xml ให้เปิดได้ด้วย HTTP 200 และเป็น HTML ภาษาเฉพาะหน้า; favicon, CSS, JS, ภาพ, QR ต้องตอบ 200
5. ตรวจหน้ามือถือและ PC และปุ่มโทร/LINE/แผนที่/TH/EN/ฟอร์มเตรียมข้อความ
6. ตรวจหมายเลข 092-564-9623 และ 065-562-9898, เวลาทำการ, ที่อยู่จริงกับข้อมูลใน Google Business Profile
7. ตั้ง Redirect 301 จาก URL เดิมที่เกี่ยวข้องไปยังหน้าใหม่ให้ถูกต้อง หากมี URL ที่เคยติด Google; อย่าลบหน้าเดิมโดยไม่วาง redirect
8. กำหนดเวอร์ชันโฮสต์หลัก https://www.aabgroups.com และ 301 จาก http / non-www ตามโครงสร้างเซิร์ฟเวอร์จริง
9. หลังเว็บไซต์ออนไลน์ ให้เพิ่ม Domain Property ใน Google Search Console, ยืนยัน DNS แล้วส่ง https://www.aabgroups.com/sitemap.xml
10. ใช้ URL Inspection ตรวจ /th/, /en/, แต่ละหน้าบริการ และ /location/ พร้อมขอ Index เมื่อเหมาะสม
11. ตั้ง GA4 รหัส Measurement ID จริงด้วยความยินยอมและนโยบายความเป็นส่วนตัวที่เหมาะสม; ทดสอบ events ผ่าน DebugView
12. เปิดดู Core Web Vitals และ coverage หลังจากมีข้อมูลจริง และแก้ไขปัญหาที่รายงาน

### สำคัญเรื่อง root กับภาษาไทย
ไฟล์ root index.html มีเนื้อหาภาษาไทยเหมือน /th/ แต่ตั้ง canonical ชี้ไป /th/ เพื่อป้องกันส่งสัญญาณหน้าแข่งกัน บนเว็บไซต์ production สามารถตั้ง 301 / → /th/ ถ้าต้องการ (แต่ต้องตรวจว่าระบบ host รองรับ); อย่าบังคับ redirect /en/ ไป /th/ ตาม IP หรือภาษา Browser

### สถานะสองหมุด Google Maps
ลูกค้ายืนยัน AAB HQ กับ All About Bimmer เป็นศูนย์เดียวและปักสองหมุดตำแหน่งเดียวกัน
แนวทาง Google โดยทั่วไปอนุญาต Business Profile เดียวต่อหนึ่งธุรกิจ/สถานที่ การมีสองหมุดธุรกิจเดียวกันเสี่ยงถูกมองเป็น duplicate; ต้องรักษาหมุดที่มีรีวิวเดิมไว้ก่อน และติดต่อ Google Business Profile Support หากจะรวมรายการ อย่าลบเองโดยไม่มีแผนรักษารีวิว
