ข้อควรรู้ก่อนเปิดใช้งาน:
1. ลิงก์ maps.app.goo.gl เป็นลิงก์เปิดแอป/แผนที่ ไม่สามารถใช้ iframe src โดยตรงได้
2. แผนที่ฝังใช้ Google Maps search แบบ iframe โดยค้นหา: AAB HQ ศูนย์บริการรถยุโรป ลาดกระบัง กรุงเทพมหานคร
3. ต้องเปิดเว็บออนไลน์ที่มีอินเทอร์เน็ตเพื่อทดสอบว่า iframe จับหมุดได้ตรงกับลิงก์จริงหรือไม่
4. เพราะไม่ได้รับ Google Maps Embed Code หรือ Place ID จากลิงก์ย่อ จึงยังยืนยันไม่ได้ว่าผลแผนที่ฝังตรงหมุด 100%
5. ปุ่มนำทางในหน้าแรกเชื่อมไปยังลิงก์ใหม่ที่เจ้าของศูนย์ให้ตรง ๆ เสมอ
6. หาก Google Maps เปลี่ยนนโยบายการฝังแผนที่ วิธีที่แม่นยำที่สุดคือเข้า Google Maps ของหมุดใหม่ → Share → Embed a map → Copy HTML แล้วแทน src iframe
